RDAP guide

Registration Data Access Protocol (RDAP) is the modern replacement for WHOIS, developed by the IETF. It provides:

🛡️ Privacy Protection

Standardized redaction of personal information

🗣️ Internationalization

Supports UTF-8 and non-ASCII characters

💻 JSON Format

Machine-readable responses for automation

🔗 RESTful API

Standardized endpoints and HTTP methods

Feature RDAP WHOIS
Format JSON Plain text (inconsistent)
Privacy ✅ Standardized redaction ❌ Varies by registrar
Internationalization ✅ UTF-8 support ❌ ASCII only
Protocol RESTful API (HTTPS) Port 43 (TCP)
Data Types Domains, IPs, ASNs, Entities Primarily domains
🏷️ handle

Unique identifier for the object

🏢 entities

Registrar, registrant, admin, tech contacts

📅 events

Registration, expiration, last changed dates

🔗 links

Related resources and self links

✅ status

Object status (active, inactive, etc.)

🆔 publicIds

IANA registry identifiers
